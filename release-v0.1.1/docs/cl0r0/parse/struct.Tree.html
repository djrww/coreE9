解析產物:源碼 + 節點表 + 配置快照 + 首未 token 統計(§1.1 / §5.3)。

每個節點子樹邊界處的解析器配置快照(重用統計的對賬依據)。

§last_tok: Vec<Option<TokKind>>

每個節點(子樹)的最後一個非 trivia token 種類(用於重用統計與對賬)。
