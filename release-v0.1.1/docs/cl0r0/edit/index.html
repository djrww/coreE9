§2.1 編輯單體(edit monoid)。

一次編輯 e = (start, old_end, new_end, text)。位移函數(照抄報告公式): shift_e(p) = p 若 p ≤ start = p + (new_end − old_end) 若 p ≥ old_end = ⊥(落在被替換區內,未定義)

機械驗證的命題: (M1) 單位元:空編輯與任意編輯複合仍是原編輯。 (M2) 位移複合 = 平移量之和(整數加法結合律——報告的「證明要點」)。 (M3) 結合律:compose(compose(e1,e2),e3) ≡ compose(e1, compose(e2,e3)) 對「可複合」三元組(複合後坐標歸一化到原源碼空間)。 (M4) apply(compose(e1,e2)) == apply(e2, apply(e1, src)) :與「先施 e1 再把 e2 的位址經 e1 位移平移」的語義一致。 (M5) 並行歸併:任意順序歸併同一批互不重疊的編輯,總編輯相同 (watch 層去抖的代數依據,報告 §2.1 的實用意義)。

is_pairwise_disjoint
